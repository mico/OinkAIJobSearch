Configure the bot environment with OINK_SOCIAL_BROWSER_ENABLED=1, OINK_SOCIAL_BROWSER_EXTENSION_ID equal to the ID above, and OINK_SOCIAL_BROWSER_TOKEN equal to the secret below. Restart the bot after changing its environment.

The token is stored only in this Chrome profile's local extension storage, not synced. It is sent only to the fixed receiver. No cookies, browsing history, or other tabs are read or exported.

Collection settings

32–512 printable ASCII characters, without spaces. Leave blank to keep an already stored token.

Login walls, CAPTCHAs, explicit access blocks, and rate limits pause only the affected source. Resolve the issue manually in a normal site tab, then use its Resume button or re-save settings to resume. The collector does not solve challenges, bypass restrictions, or use undocumented APIs. Sources with an empty configured list are not collected.

Collection opens inactive, temporary tabs and closes only tabs it created. A listing page gets at most three scrolls and about 45 seconds. Missing Reddit bodies are read from captured post permalinks without scrolling comments, while time remains in the ten-minute run. Only structurally complete posts with an observed timestamp are sent; the bot's AI scorer decides relevance.
