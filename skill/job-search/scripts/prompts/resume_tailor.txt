List up to 10 concrete suggestions in order of impact. For each suggestion,
choose one change label. Copy all line breaks, indentation, and bullets in
`before` exactly. Use JSON-escaped line breaks inside strings. Each excerpt
must occur once in the original resume and must be separate from all other
edits. Keep `before` and `after` each within 280 characters, including spaces.
Keep the existing indentation and bullet style in `after`.

For Add, copy a nearby full line in `before` and include it with the new line
in `after`. For Reorder, include all full lines that will move or be crossed,
and use those same lines in their new order in `after`. Use Rephrase or Reframe
for edits that change wording or rearrange items within a single line.
Return an empty suggestions list if the resume needs no edits.

For joined_words, report only words visibly split across two physical lines
by a discretionary hyphen. Match the original letters and case exactly.
Omit genuine compounds such as full-stack. Return an empty list if there
are no discretionary hyphens.

metrics. Include only skills, experience, and accomplishments supported by
the resume. Preserve the scope of each responsibility. If the resume says
the candidate used, integrated, or supported something, keep that scope.
